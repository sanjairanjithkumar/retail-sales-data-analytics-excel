# Retail Sales & Profitability Dashboard

📊 An interactive Excel dashboard built to analyze retail sales, costs, profitability, products, categories, regions, stores, and sales channels.

## Dashboard Preview

![Retail Sales & Profitability Dashboard](dashboard_image.png)

## Project Overview

I created this project to analyze retail sales data and turn it into an interactive Excel dashboard.

The dashboard provides a clear view of sales, cost, orders, profit, product performance, categories, regions, stores, payment methods, and sales channels. Users can apply filters to explore the data from different business perspectives.

## From Data to Dashboard

I started with raw retail sales data containing information about orders, customers, products, stores, sales channels, payments, costs, sales, profit, and returns.

After preparing and organizing the data in Excel, I used formulas, PivotTables, PivotCharts, slicers, and KPI cards to build the final dashboard.

The main goal was to create a simple and interactive report that makes it easier to understand sales and profitability performance.

## Business Questions

The dashboard was created to answer questions such as:

- What are the total sales and total costs?
- How many orders were placed?
- Which categories generate the highest sales?
- Which products generate the highest profit?
- Which region performs best in terms of sales and profit?
- Which cities contribute the most to sales?
- How do online and store sales compare?
- Which payment methods are most commonly used?
- How does sales and profit performance change by year?
- Which categories have higher return rates?
- Which stores and products contribute more to profitability?

## How to Use

1. Download the Excel dashboard file.
2. Open the workbook using Microsoft Excel.
3. Go to the `Dashboard` worksheet.
4. Use the available slicers and filters.
5. Select different brands, channels, dates, payment methods, regions, cities, stores, or products.
6. Explore the KPIs and charts to understand sales and profitability performance.
